# Proyecto de Automatización QA (preentrega) - Fabian Angarita M

## Propósito del Proyecto

El objetivo es implementar pruebas automatizadas para validar funcionalidades clave del sitio web (https://www.saucedemo.com/), tales como:

- Inicio de sesión de usuarios
- Navegación en el inventario
- Selección de productos
- Agregado de productos al carrito de compras
- Evaluar la incorporacion de los item al carrito de compras

Con esto se busca garantizar la calidad del sistema mediante pruebas automatizadas utilizando buenas prácticas de QA.


##  Tecnologías Utilizadas

Las principales herramientas y tecnologías empleadas en este proyecto son:

- **Python 3.14**
- **Pytest** - Framework para ejecución de pruebas
- **Selenium WebDriver** - Automatización de navegador
- **ChromeDriver** - Driver para el navegador Google Chrome
- **Pytest HTML** - Pra leer los reportes
- **Git** - Controlar y gestionar cambios en los archivos
- **Pathlib** - Libreria
