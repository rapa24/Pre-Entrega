# Selectors - Proyecto 

## Login Page
- Input Usuario: #user-name (id del campo de texto usuario)
- Input Contraseña: #password (id del campo para contraseña)
- Login button: #login-button (id del del campo de entrada tipo submit)
- Mensaje de error: [data-test="error"] - .error-message-container h3 (Subtitulo con el mensaje de error)

## Inventory Page
- Titulo producto: .inventory_item_name (clase para titulo de product)
- Precio del producto: .inventory_item_price (precio producto)
- Login button: #login-button (id del del campo de entrada tipo submit)
- button: .btn_inventory (clase boton para agregar al carrito) 
- carrito: .shopping_cart_badge / .shopping_cart_link (carrito de compras)
- Menu button: #react-burger-menu-btn (id menu hamburgesa)
